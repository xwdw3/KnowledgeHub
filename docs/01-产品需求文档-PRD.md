## 1. 产品概述

### 1.1 一句话定义

一个部署在企业内网、以企业自有文档为唯一知识来源的智能问答系统：员工用自然语言提问，系统从制度、业务、技术资料中检索出准确片段，并给出**有出处、可核对**的答案。

### 1.2 产品定位

| 维度 | 定位描述 |
| --- | --- |
| 是什么 | 企业内部知识的"统一入口 + 智能问答助手" |
| 不是什么 | 不是通用聊天机器人，不是全文搜索引擎，不是文档网盘 |
| 核心差异 | 知识来源限定为企业私有文档，答案必须带原文出处，数据不出内网 |

### 1.3 目标用户与核心场景

| 用户角色 | 典型场景 | 当前痛点 | 期望结果 |
| --- | --- | --- | --- |
| 普通员工 | 查报销标准、请假规则、系统操作流程 | 要翻好几份文件，或问同事 | 一句话提问，5 秒内拿到条款原文 |
| 新入职员工 | 快速了解公司制度与业务规范 | 不知道知识在哪，反复打扰导师 | 自助式知识获取，降低培训成本 |
| 业务/职能管理者 | 政策口径统一、减少重复答疑 | 同问题被问几十遍，口径不一 | 标准答案沉淀，重复咨询下降 |
| 知识库管理员 | 上传、更新、下架文档 | 无法判断哪些文档有用、哪些过期 | 有入库状态与召回数据可看 |
| IT/安全负责人 | 数据合规、权限隔离、审计 | 担心敏感内容外发或被越权访问 | 数据不出内网，访问全程留痕 |

### 1.4 核心价值主张

1. **答案可信**：每条答案都能追到原文文件与片段，杜绝"AI 编的"。
2. **知识可用**：语义理解，不用记关键词也能搜到。
3. **边界可控**：数据私有化部署，权限按文档粒度隔离。
4. **成本可算**：缓存与混合检索降低大模型调用量。

## 2. 产品目标与成功指标

### 2.1 北极星指标

**周活跃提问用户数（WAU）** —— 反映知识库是否真正嵌入员工日常工作流。

### 2.2 分阶段目标

| 阶段 | 目标 | 关键结果（KR） |
| --- | --- | --- |
| MVP（已达成） | 打通"上传→检索→问答"闭环 | 支持 4 类文档；问答可用；答案带出处 |
| V1.1 | 让答案更准、更快 | 召回命中率 ≥90%；缓存命中 <200ms；平均响应 <5s |
| V1.2 | 让系统可管、可审 | 权限组落地；全链路日志与指标看板上线 |
| V2.0 | 让知识库进入工作流 | 接入企业微信/钉钉；支持表格与扫描件 |

### 2.3 上线后效果指标

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 问答采纳率 | 用户未追问同一问题即视为采纳 | ≥ 80% |
| 无答案率 | 返回"未找到相关内容"的比例 | ≤ 15% |
| 平均响应时长 | 从提问到首字返回 | < 5 s |
| 重复咨询下降率 | 与上线前人工咨询量对比 | ≥ 50% |
| 知识覆盖率 | 被询问过且有文档支撑的问题占比 | ≥ 85% |

## 3. 产品范围

### 3.1 本期范围（In Scope）

- 文档上传、解析、入库、删除
- 自然语言问答（多轮会话）
- 混合检索（向量 + 关键词 + 重排）
- 原文片段溯源
- Web 问答工作台
- 开放 REST API（供内部系统集成）

### 3.2 暂不纳入（Out of Scope）

| 暂不做 | 原因 |
| --- | --- |
| 文档在线编辑与协同 | 非核心路径，交给 OA/网盘 |
| 复杂表格/图片理解 | 依赖 OCR 与多模态，V2.0 规划 |
| 多租户 SaaS 化 | 先做单企业私有化，避免过度设计 |
| 知识图谱构建 | 投入产出比在早期不划算 |
| 模型微调训练 | RAG 已能覆盖，微调留作后期优化手段 |

## 4. 业务流程

### 4.1 知识入库流程（管理员侧）

```
选择文档 → 系统校验格式(.txt/.md/.pdf/.docx)
        → 自动解析文本
        → 智能切片（按段落与中文标点递归切分）
        → 向量化入库
        → 返回"入库成功，共 N 个片段"
        → 失败时给出明确原因（格式不支持 / 提取文本为空 / 服务异常）
```

### 4.2 问答流程（员工侧）

```
输入问题 → 校验（非空 / ≤1000 字）
        → 恢复会话上下文（同一会话多轮连贯）
        → 缓存匹配（命中直接返回）
        → 检索知识库（按用户权限过滤）
        → 精排选出最相关片段
        → 大模型基于片段生成答案
        → 返回答案 + 引用来源
```

### 4.3 异常流程

| 异常 | 系统行为 | 用户感知 |
| --- | --- | --- |
| 文档无权限 | 检索结果为空 | "未找到您有权访问的相关内容" |
| 知识库无相关内容 | 不强行作答 | "知识库中暂未收录该问题，建议联系 XX 部门" |
| 模型服务超时 | 重试 → 降级提示 | "服务繁忙，请稍后重试" |
| 上传格式不支持 | 拦截并提示 | "仅支持 txt/md/pdf/docx" |

### 5.2 详细功能说明（P0）

#### F-01 文档上传入库

- **入口**：Web 工作台右侧"文档管理"面板，或调用 `POST /api/upload`
- **输入**：单个文件（暂不支持批量）
- **校验**：扩展名白名单、文件可解析、解析后文本非空
- **输出**：成功返回"✅ 文件名 入库成功"；失败返回具体原因
- **规则**：同名文档重复上传视为**覆盖更新**（先删旧片段再写新片段）

#### F-02/F-03 解析与切片

- **解析**：PDF 逐页提取、Word 逐段提取、TXT/MD 直读
- **切片**：默认 450~500 字符，重叠 80 字符；切分优先级 `段落 > 换行 > 句号 > 分号 > 空格`
- **要求**：切片不得切断完整句子；每片保留来源文件名与权限标签

#### F-06 智能问答

- **输入**：自然语言问题，≤1000 字符
- **交互**：回车或点击发送；答案流式/整段返回（当前为整段）
- **多轮**：同一 `session_id` 共享上下文；点击"新建对话"清空
- **工具调用**：系统可自主决定是否检索知识库、是否需要计算，最多 3 轮，防死循环

#### F-07 检索与精排（用户不可见，但决定体感）

- 双路召回：语义向量 + 关键词，互补覆盖"同义表达"与"专有名词"
- 融合排序后精排取前 2 段作为上下文
- **约束**：上下文必须来自用户有权限的文档

#### F-08 引用溯源

- 答案下方展示：来源文件名 + 命中片段原文
- 支持展开/折叠；点击可复制原文
- **要求**：答案中出现的每条关键结论，都应能对应到至少一个片段

#### F-09 无答案拒答

- 触发条件：召回为空，或精排相关度低于阈值
- 行为：明确告知"知识库中暂无相关内容"，**不猜测、不编造**
- 可附建议：换个说法提问 / 联系知识库管理员

### 5.3 详细功能说明（P1）

| 功能 | 要点 |
| --- | --- |
| F-05 文档列表 | 展示文件名、片段数、上传人、上传时间、状态；支持搜索与删除 |
| F-10 会话管理 | 会话列表、重命名、删除；会话不跨用户共享 |
| F-11 权限分组 | 按部门/项目设权限组；用户提问时自动带入其权限组 |
| F-12 缓存 | 高频问题缓存（TTL + 文档变更失效）；向量结果缓存 |
| F-14 可观测 | 问答量、无答案率、平均耗时、熔断次数、热门问题 Top20 |

## 6. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 缓存命中 <200ms；完整问答 P95 <5s；入库 10MB 文档 <60s |
| 并发 | 单实例支持 20 并发问答（后续水平扩展） |
| 可用性 | 核心链路 ≥99.5%；外部模型异常时降级不崩溃 |
| 安全 | 数据不出内网；权限过滤在检索阶段生效；密钥不入代码库 |
| 合规 | 问答全链路留痕，可追溯"谁在何时问了什么、看到了哪些文档" |
| 兼容 | Chrome/Edge 最新版；移动端响应式（V2.0） |
| 可维护 | 日志结构化；配置全部外置到环境变量 |

## 7. 交互与界面设计要点

### 7.1 页面结构（当前 Web 工作台）

```
┌─────────────────────────────────────────────┐
│  📚 企业智能知识库                            │
├──────────────────────────┬──────────────────┤
│  对话区（气泡流）          │  📁 文档管理       │
│  ┌────────────────────┐  │  上传文档          │
│  │ 用户：报销上限多少？ │  │  [选择文件]        │
│  ├────────────────────┤  │  [上传入库]        │
│  │ 助手：按《差旅费用   │  │  ─────────────    │
│  │ 管理办法》第 12 条…  │  │  删除文档（文件名）  │
│  │ 📎 来源：差旅…pdf   │  │  [输入框]          │
│  └────────────────────┘  │  [删除文档]        │
│  [输入框............][发送]│                  │
│  [新建对话]               │                  │
└──────────────────────────┴──────────────────┘
```

### 7.2 关键交互规则

| 场景 | 规则 |
| --- | --- |
| 发送中 | 按钮置灰，显示"思考中…"，防重复提交 |
| 空问题 | 不发送，输入框轻微抖动提示 |
| 答案渲染 | 支持换行与简单 Markdown；长答案自动撑高对话区 |
| 无答案 | 使用中性色提示卡片，不使用红色报错样式 |
| 上传反馈 | 上传中显示进度文案；成功绿色、失败红色并给出原因 |
| 新建对话 | 清空当前对话区，生成新 session，不影响其他会话 |

### 7.3 体验优化项（待排期）

- 答案**流式输出**（降低等待焦虑）
- 引用片段**高亮命中关键词**
- 答案底部"👍 有用 / 👎 没用"反馈按钮（用于质量运营）
- 热门问题推荐（降低冷启动提问门槛）

## 8. 数据与埋点需求

| 事件 | 触发时机 | 用途 |
| --- | --- | --- |
| `question_asked` | 用户提交问题 | 问答量、热门问题 |
| `answer_returned` | 答案返回 | 耗时分布、熔断率 |
| `no_answer` | 拒答触发 | 知识盲区分析 |
| `doc_uploaded` | 上传成功 | 知识库增长趋势 |
| `doc_deleted` | 删除成功 | 变更审计 |
| `feedback` | 用户点赞/点踩 | 答案质量评估 |

**知识盲区分析**：将 `no_answer` 的问题聚类，反向输出"建议补充的文档清单"，形成知识运营闭环。

## 10. 验收标准

| 编号 | 验收项 | 通过标准 |
| --- | --- | --- |
| A1 | 文档入库 | 4 类格式均可上传并返回片段数，错误格式被明确拦截 |
| A2 | 问答准确性 | 50 条标准问题中，≥45 条答案与原文条款一致 |
| A3 | 答案溯源 | 100% 答案可展开查看来源片段 |
| A4 | 拒答行为 | 库外问题不编造，明确提示无相关内容 |
| A5 | 权限隔离 | A 部门用户无法检索到 B 部门文档（返回空） |
| A6 | 性能 | 缓存命中 <200ms，完整问答 P95 <5s |
| A7 | 多轮对话 | 追问"那出差呢"能基于上文正确理解 |
| A8 | 稳定性 | 模型服务中断时接口返回友好提示，不 500 崩溃 |

## 11. 依赖与风险

| 类型 | 内容 | 应对 |
| --- | --- | --- |
| 依赖 | Embedding / Rerank / LLM 外部服务 | 多供应商备份，接口标准化便于切换 |

| 风险 | 使用率低（冷启动） | 嵌入企微/钉钉，进入日常场景 |
